## こんなアプリです

- 1回5問から遊べるので、すきま時間に少しずつ進められます
- 最初に3種類のキャラクターから相棒をえらび、名前を登録して自分のアカウントを作ります
- 正解すると経験値（XP）がたまり、キャラクターが「たまご」から「レジェンドナース」まで8段階に成長します
- 間違えた問題は「間違いノート」に自動でたまり、そのまま復習リストになります
- 勉強タイマーで勉強時間を記録できます。スタートを押せば、アプリを閉じても計測が続きます
- グループや友達追加で、仲間の勉強時間・いま勉強中か・成績・キャラの成長が見られます
- 第116回看護師国家試験（2027年2月14日）までの残り日数と、合格ラインまでの距離を表示します

## あそべるモード

| モード | 内容 |
| --- | --- |
| おまかせ10問 | まだ解いていない問題と、間違えた問題を優先して10問出題 |
| 分野クエスト | 12分野から選んで5問。正解済みの割合に応じて★が1〜3個つく |
| 必修チャレンジ | 必修問題10問。8問正解（8割）で合格 |
| タイムアタック | 60秒で何問正解できるかに挑戦 |
| サバイバル | ハート3つからスタートし、間違えるたびに1つ減る |
| 状況設定バトル | 患者さんの事例を読んで3問に答える（1問2点）。正解すると患者さんの元気ゲージが上がる |
| 計算ドリル | 点滴の滴下数（成人用・小児用）、輸液ポンプの流量、薬液量、消毒液の希釈、酸素ボンベの使用可能時間、BMI。毎回数値が変わる |
| ミニ模試 | 必修10問＋一般15問＋状況設定2ケース（計31問）。本番の合格基準と同じ比率で合否を判定 |
| 間違いノート | 間違えた問題だけを復習。2回続けて正解すると卒業 |

- はじめて開くと「キャラクターをえらぶ → 名前を登録 → アカウントをつくる」の順に進みます
- キャラクターはあとから変えられます（レベルや記録はそのまま）
- 1台の端末に複数のアカウントを作れます。右上のキャラのアイコンから、切り替え・追加・削除ができます。家族や友達と端末を共有するときに便利です
- 登録した名前は、友達機能で友達にも表示されます

## 勉強タイマー

- ホーム画面の「スタート」で計測開始。開始時刻を保存しているので、アプリを閉じたりスマホをロックしたりしても計測は続きます
- 「ストップ」を押すと計測した時間が表示され、必要なら直してから記録できます（日付をまたいだ場合は日ごとに自動で分けます）
- スタートを押し忘れた日も、「時間を記録・修正」からいつの日の勉強時間でも書き込み・修正できます
- タイマーで記録した時間は経験値にもなります（1分＝1XP、1回あたり最大180XP）

## 友達・グループ

- 「ともだち」タブで「友達機能をはじめる」を押すと、自分専用の **友達番号**（8けた）が使えるようになります（はじめるまでは何も送信しません）
- **グループ**：「グループを作る」で8けたのグループ番号ができます。番号を友達に送り、「番号で参加」から入ってもらいます
- **友達追加**：相手の友達番号を入れると、その人の様子が見られます（一方通行なので、お互いに見るにはお互いを追加します）
- 見られる項目：いま勉強中か（経過時間つき）・勉強時間（今日／今週）・問題の成績（今日解いた数・累計・正答率）・キャラクターの成長・連続日数・シールの数
- **表示する項目** と **友達に見せる項目** は、それぞれ自分で選べます

## ごほうび

- **コイン**：1問正解ごとに1枚。高得点のボーナスで5枚、ミッション達成で10枚もらえます
- **ごほうびガチャ**：20コインで1回。聴診器やナースキャップなど、看護グッズのシールが全20種類（ノーマル・レア・スーパーレア）
- **バッジ**：「1週間皆勤」「コンボ10」「ミニ模試合格」など全14種類
- **きょうのミッション**：毎日3つ（10問解く・5問連続正解・計算ドリルか状況設定に挑戦）

## 合格ラインについて

- **必修問題**：50点中40点以上（8割・絶対基準）
- **一般問題＋状況設定問題**：第115回（2026年）は249点中166点以上。毎年変わる相対基準です
- 「きろく」タブでは、いまの正答率から本番で取れそうな点数を推定して表示します

試験日と合格基準は、厚生労働省の発表をもとに記載しています。

## 記録の保存について

- 学習の記録は、アプリを開いたブラウザの中（localStorage）に保存されます
- 友達機能を使うと、「友達に見せる項目」に選んだ情報だけが、公開のMQTT中継サーバー（broker.emqx.io / broker.hivemq.com）を通して送られます。送る前にグループ番号・友達番号から作った鍵（AES-256-GCM）で暗号化するので、番号を知らない人には読めません。友達機能を使わなければ何も送信されません
- ブラウザのデータを削除したり、別の端末やブラウザで開いたりすると、記録は引き継がれません
- スマホではホーム画面に追加すると、アプリのように開けて便利です
  - **iPhone**：Safariで開き、共有ボタン →「ホーム画面に追加」
  - **Android**：Chromeで開き、右上のメニュー →「ホーム画面に追加」

## ご注意

- 問題と解説はすべてオリジナルで、実際の国家試験問題ではありません
- 医療・看護の内容は、教科書や最新のガイドラインでもあわせて確認してください
- 厚生労働省や試験の実施機関とは関係のない、個人制作の学習アプリです
